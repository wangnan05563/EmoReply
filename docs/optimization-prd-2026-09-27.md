# EmoReply 优化迭代 PRD（2026-09-27）

> 来源：同类产品竞品调研（docs/competitive-research-2026-09-27.md，11 个竞品）+ 用户反馈累积。
> 定位不变：输入法内零切换闭环（读屏/粘贴 → 候选 → 原地注入）+ 零留存隐私。
> 战略约束：自动发送不做（人工采纳是隐私护城河）；全键盘输入维持不做（Smartbar/快捷动作属 AI 工具条范畴）。

## 一、目标与成功指标

- 目标：补齐竞品已验证的体验短板（P0），落地差异化扩展（P1），建立主题/UI 体系。
- 成功指标：候选采纳率提升；读屏→注入全链路 ≤5s；用户可选主题 ≥6 套；暗色模式全覆盖。

## 二、功能需求

### FR-7 体验优化（M-P0 快赢 + M-P2 长期）

- **FR-7.1【P0】候选换一批（Regenerate）**
  候选区尾部「换一批」入口：保留当前会话上下文与人设配置，重新调用生成器产出新候选；新候选替换旧列表，历史会话不清空。
  - 验收：群聊与单聊场景各点击一次，新候选与旧候选不重复；连点有防抖（生成中禁用）。
- **FR-7.2【P0】候选一键复制**
  每条候选右侧新增复制按钮：点击复制纯文本到系统剪贴板并 Toast 确认；不注入宿主（非 IME 宿主场景也可用）。
  - 验收：复制后剪贴板内容与候选一致；微信输入框焦点不受影响。
- **FR-7.3【P0】语气强度滑杆**
  语气控制从 4 档离散风格升级为连续强度调节（理性克制 ↔ 轻松自然 ↔ 活泼外向），滑杆状态持久化，生成 prompt 注入强度描述。
  - 验收：同一消息在滑杆两端产出的候选语气差异明显；重启后滑杆位置保持。
- **FR-7.4【P1】读屏过程进度反馈**
  多屏读屏（3 屏）等待期显示「已读第 N/3 屏…」阶段提示；完成后显示读取行数。
  - 验收：读屏期间汇总格文字随阶段变化；完成后恢复常规态。
- **FR-7.5【P1】首次引导向导**
  三步 onboarding：①启用 EmoReply 键盘 ②授权通知/无障碍权限 ③引导完成第一次生成；状态可跳过、完成标记持久化。
  - 验收：全新安装首次启动出现向导；三步后直接进入主界面。
- **FR-7.6【P1】使用统计面板**
  今日/累计采纳数、分应用分布、平均生成耗时；本地计数（零留存边界内，仅计数不存内容）。
  - 验收：采纳候选后计数+1；重启后数据保持。
- **FR-7.7【P2】触觉反馈**
  候选采纳/注入成功/长按触发 Haptic 反馈，强度可调（含关闭）。
  - 验收：开关关闭后无震动；开启后三处触发点均有反馈。

### FR-8 功能扩展（M-P1A 智能增强 + M-P2）

- **FR-8.1【P1】端侧离线模型试点**
  集成 MediaPipe LLM Inference（Gemma 3n 端侧）作为可选推理后端：飞行/无网/隐私模式全功能可用；与云端后端同接口可切换。
  - 验收：断网状态完成一次候选生成；模型文件不随 APK 打包（首次下载）。
- **FR-8.2【P1】关系×场景×目的三维筛选**
  生成前可选「对方关系（领导/客户/恋人/朋友）+ 沟通目的（安抚/拒绝/推进/闲聊）」，作为 prompt 约束注入；默认继承上次选择。
  - 验收：同一条消息在「领导+安抚」与「朋友+调侃」下产出候选风格差异明显。
- **FR-8.3【P1】防诈骗与风险提示**
  检测转账/借钱/威胁/索要验证码类消息：候选置顶风险提醒（「疑似诈骗，建议核实」），且不产出顺从诈骗话术的候选。
  - 验收：构造 5 类诈骗样本，全部触发提醒且无顺从候选；正常消息零误报。
- **FR-8.4【P1】场景化开场建议**
  无对话上下文时 ✨ 长按菜单新增「开场」模式：选场景（破冰/重连/节日祝福）生成开场话术。
  - 验收：三种场景各生成 3 条开场候选。
- **FR-8.5【P2】联系人记忆深化**
  人设库扩展「上次聊到」跨会话记忆（本地 AES-256 加密，仅设备）；生成时注入最近话题避免重复。
  - 验收：同一联系人第二次生成时引用上次话题；清空数据后记忆清零。
- **FR-8.6【P2】再互动建议**
  会话超 48h 未回复：汇总格提示低压力重启话术（一键生成「轻量回访」候选）。
  - 验收：构造超时通知触发提示；正常时限内不提示。
- **FR-8.7【P2】快捷动作面板**
  🖌 美化扩展为动作族：长按弹出「改写/总结/翻译/扩写」菜单，动作作用于输入框文本。
  - 验收：四个动作对同一段文本产出对应结果；空文本提示。
- **FR-8.8【P2】话术收藏夹**
  候选长按收藏（本地加密存储）；生成时同类场景优先展示收藏话术。
  - 验收：收藏→重启→同类生成中出现收藏项；取消收藏生效。

### FR-9 UI 升级（M-P0/M-P1B）

- **FR-9.1【P0】暗色模式**
  跟随系统深浅色自动切换；AMOLED 纯黑可选；键盘面板/候选区/APP 全覆盖。
  - 验收：系统切深色后键盘与 APP 即时跟随；AMOLED 模式纯黑无发灰。
- **FR-9.2【P1】图标行 Smartbar 化**
  图标行改为「高频图标 + ··· 溢出菜单」：低频功能（输入法切换/美化等）收纳第二行，腾出空间给状态与快捷操作。
  - 验收：溢出菜单收纳后全部功能可达；主行图标 ≤4 个。
- **FR-9.3【P1】候选卡片标签化**
  候选理由从灰字升级为分类标签（情感共鸣/行动建议/边界保持/幽默化解），视觉扫读效率提升。
  - 验收：每条候选恰有一个标签；标签与理由语义一致。
- **FR-9.4【P2】布局过渡动画**
  双栏/精简/展开收起切换加 200ms 过渡动画，避免布局跳变。
  - 验收：四种布局状态切换无可感知跳变。

### FR-10 主题系统（M-P1B + 远期）

- **FR-10.1【P1】Material You 动态取色**
  Android 12+ 从壁纸取色生成键盘配色（参考 fcitx5-android Monet 实现：surfaceContainer/primary 等 token 映射）；壁纸变更即时刷新。
  - 验收：更换壁纸后键盘配色跟随；Android 11 及以下自动回落默认主题。
- **FR-10.2【P1】主题预设包**
  6-9 套预设：浅色/深色/AMOLED 黑/Nord/Monokai/品牌色；主题选择持久化。
  - 验收：切换主题即时生效并重启保持。
- **FR-10.3【P2】自定义强调色**
  候选选中态/图标激活态强调色可自选（单色）。
  - 验收：更换强调色后三处元素即时生效。
- **FR-10.4【P3】DIY 主题编辑器**
  完整颜色自定义+实时预览+导入导出（远期，需求确认后立项）。
  - 验收：自定义主题保存/应用/导出全部可用。

## 五、非目标（本轮明确不做）

- 自动发送回复（人工采纳为隐私与安全护城河）；
- 全键盘字母输入（维持 2026-09-26 拍板）；
- 云端账号体系与同步（保持零账号）。
