# 端侧模型下载指南

> 核查：2026-10-31（T03716）对照 `MediaPipeOnDeviceGenerator.kt`、`OnDevicePresets.kt` 与 `activity_main.xml` 当前实现。

## 问题背景

用户在"首次下载地址"输入框中填写 Kaggle 模型页面 URL（如 `https://www.kaggle.com/models/google/gemma-3/TfLite/gemma-3-270m-it-int8/1/download`）并点击"下载模型到应用目录"时，会收到错误提示。

## 根本原因

经过实测验证（`curl -sI` 测试），Kaggle 的模型文件**不存在匿名直链**：

- **页面 URL**（`.../models/.../1/download`）→ HTTP 404 Not Found
- **API URL**（`.../api/v1/models/.../1/download`）→ HTTP 403 Permission denied

两者都需要登录凭据才能访问。应用内的下载器没有凭据配置位，因此无法通过 Kaggle 直接下载。

## 已完成的改进

### 1. 重构下载逻辑（`MediaPipeOnDeviceGenerator.kt`）

**之前的问题**：
- 不检查 HTTP 状态码，任何异常都显示通用错误"下载失败或地址不可用"
- 会把 HTML 错误页保存为 `.task` 文件，导致后续模型加载崩溃

**现在的行为**：
- 返回 `DownloadOutcome` sealed class（`Success`/`Failure`），而非 `File?`
- 手动跟随重定向（最多 5 次），支持跨协议跳转
- 按 HTTP 状态码分类错误并给出具体中文提示：

| 错误类型 | HTTP 代码 | 用户看到的提示 |
|---------|----------|--------------|
| 需要鉴权 | 401/403 | "该地址需要登录鉴权（HTTP 401/403）：Kaggle / HuggingFace 的模型文件没有匿名直链。两条可行路径：① 在电脑上用 Kaggle CLI 或浏览器登录后下载，再点「常用模型」按钮，按其状态行给出的 adb 命令把文件放进应用目录并回填路径；② 换成你自己服务器上带凭据参数的文件直链（同一 Wi-Fi 下也可用 `python -m http.server` 把本地文件暴露成 http 直链填这里）" |
| 地址不存在 | 404/410 | "地址不存在（HTTP 404）：这多半是网页或「下载」按钮的链接，不是文件直链。Kaggle 模型文件需登录才能取，建议在电脑上下载后 adb push（用「常用模型」按钮填的路径）" |
| 返回网页 | content-type = text/html | "该地址返回的是网页（text/html）而非模型文件，通常是登录页或未授权的跳转。请改用文件直链，或在电脑上下载后 adb push" |
| 文件太小 | < 1MB | "实际下载 XX KB，远小于模型体积，判定为无效内容已删除。请改用文件直链或 adb push" |

- 文件名从 URL 末段提取，避免不同模型互相覆盖
- 下载进度实时显示："下载中…已收 XMB"

### 2. 更新 UI 提示文案（`activity_main.xml`）

"首次下载地址"输入框的 hint 从：
> "可直连的 .task 链接，Gemma 需自备鉴权链接"

改为：
> "首次下载地址（须为文件直链；Kaggle 需登录鉴权，无直链时请改用 adb push）"

### 3. 更新预设模型信息（`OnDevicePresets.kt`）

当前设置页提供三个预设（按钮文案 → 落地文件名）：

| 预设 | 文件名 | 说明 |
|---|---|---|
| Gemma 2 2B · int8 | `gemma2-2b-it-cpu-int8.task` | 官方 MediaPipe 示例默认模型，实测约 2.7 GB，内存占用高 |
| Gemma 1.1 2B · int4 | `gemma-1.1-2b-it-cpu-int4.bin` | 更小的备选，注意是 `.bin` 格式而非 `.task` |
| Gemma 3 270M · int8 | `gemma-3-270m-it-int8.task` | 参数量最小、最快；需登录 Kaggle 或用 CLI 下载后 adb push |

- Gemma 3 270M 的 `sourcePage` 指向 Kaggle 页面：`https://www.kaggle.com/models/google/gemma-3n`
- hint：`参数量最小、最快的新模型；需登录 Kaggle 或用 CLI 下载，再按下方命令 adb push`
- 注释明确说明 Kaggle 不提供匿名直链，「打开官方下载页」仅用于获取文件版本和 CLI 指令

### 4. 模型落地目录（`OnDevicePresets.PUSH_TARGET_DIR`）

模型统一放在**应用私有 cache 目录**，而不是 `/data/local/tmp/`：

```
/data/data/com.emoreply.poc/cache/<文件名>
```

该目录应用天然可读；shell 侧需借助 `run-as`（debug 包可调试）放开写权限后才能 `adb push` 进来，
推完再把文件权限收回到 755。设置页「常用模型」按钮会给出可直接复制的三条命令。

## 可行的下载方案

### 方案 A：Kaggle CLI（推荐）

```bash
# 1. 安装 Kaggle CLI
pip install kaggle

# 2. 配置 API key
# 从 https://www.kaggle.com/settings/account 获取 API key
# 保存到 ~/.kaggle/kaggle.json

# 3. 下载模型（以 Gemma 3 270M 为例）
kaggle models get google/gemma-3n --variation gemma-3-270m-it-int8

# 4. 传到手机的应用私有 cache 目录（debug 包用 run-as 放开写权限）
adb shell "run-as com.emoreply.poc chmod 777 /data/data/com.emoreply.poc/cache"
adb push gemma-3-270m-it-int8.task /data/data/com.emoreply.poc/cache/gemma-3-270m-it-int8.task
adb shell "run-as com.emoreply.poc chmod 755 /data/data/com.emoreply.poc/cache/gemma-3-270m-it-int8.task"
```

### 方案 B：浏览器手动下载

1. 访问 [Kaggle Gemma 3n 模型页](https://www.kaggle.com/models/google/gemma-3n)
2. 登录 Kaggle 账号
3. 选择 "LiteRT" 变体
4. 选择具体版本（如 `gemma-3-270m-it-int8`）
5. 点击下载按钮
6. 下载完成后传到手机的应用私有 cache 目录：
   ```bash
   adb shell "run-as com.emoreply.poc chmod 777 /data/data/com.emoreply.poc/cache"
   adb push <下载的文件> /data/data/com.emoreply.poc/cache/<下载的文件名>
   adb shell "run-as com.emoreply.poc chmod 755 /data/data/com.emoreply.poc/cache/<下载的文件名>"
   ```

### 方案 C：使用应用内"常用模型"按钮

如果模型文件已经推送到应用的私有 cache 目录：

1. 在应用设置页点击"Gemma 3 270M · int8"预制按钮
2. 路径会自动填充为 `/data/data/com.emoreply.poc/cache/gemma-3-270m-it-int8.task`
3. 开启"端侧离线"开关即可

## 技术细节

### DownloadOutcome sealed class

```kotlin
sealed class DownloadOutcome {
    data class Success(val file: File) : DownloadOutcome()
    data class Failure(val reason: String) : DownloadOutcome()
}
```

### 关键常量

- `MAX_REDIRECTS = 5` - 最大重定向次数
- `MIN_MODEL_BYTES = 1L shl 20`（1 MB） - 模型文件最小体积阈值（声明体积与实写体积都会校验）
- `USER_AGENT = "EmoReply/1.0 (Android; LiteRT model fetch)"` - 请求头
- `PUSH_TARGET_DIR = "/data/data/com.emoreply.poc/cache"` - 模型落地目录

### 文件名提取逻辑

```kotlin
internal fun fileNameOf(modelUrl: String): String {
    val last = modelUrl.trim().substringAfterLast('/').substringBefore('?').substringBefore('#')
    val name = last.filter { it.isLetterOrDigit() || it in "._-" }.take(80)
    return if (name.length >= 5 && name.contains('.')) name else "emoreply_model.task"
}
```

这样确保：
- 去除查询参数和锚点
- 只保留合法字符（字母、数字、`.`、`_`、`-`）
- 防止目录穿越攻击（过滤掉 `../`）
- 长度限制为 80 字符
