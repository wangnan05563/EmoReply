## 关联需求（PRD/SRS 原文摘录，含验收准则）

### FR-3.1
- **FR-3.1【P0】** 基于可用上下文 + 关系 + 情绪 + 用户人设，调用云端 LLM 生成 2–3 个候选。
  - *上下文获取策略*（解决只读约束）：① 近期通知拼装伪历史（同一会话最近 N 条）；② 用户手动粘贴补全（FR-1.5）；③ 企业/授权场景取真实历史（二期）。**质量边界**：只读通知下上下文有限，回复以"礼貌得体、不编造事实"为下限，不承诺记忆长程对话。
  - *验收*：候选生成成功率 ≥ 95%（网络正常）；默认产出 2–3 条；不出现编造对方未提及事实。

### FR-5.2
- **FR-5.2【P2】** 联系人关系与历史摘要（默认本地存储，加密）。历史来源受限于只读捕获（见 FR-3.1 上下文策略），不完整时不臆造。
  - *验收*：本地加密存储可用；无历史时不生成虚构长程记忆。
